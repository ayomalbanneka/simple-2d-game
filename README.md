# Simple 2D Game

## How to Run
Open the `index.html` file in your web browser to start the game.

## How to Play
- Press **Enter** to begin running.
- Press **Spacebar** to jump over obstacles.
- Avoid flames and other obstacles to keep running and increase your score.
- The game ends if you hit an obstacle.

## Project Structure
- `index.html` – Main game file.
- `css/style.css` – Game styles.
- `js/script.js` – Game logic and controls.
- `images/` – Sprites and backgrounds.
- `audio/` – Sound effects.

## Requirements
No installation needed. Works in any modern browser.
